# Client logos

Put client logo files in this folder. The "Our Clients" section appears
automatically on the homepage and Projects page (hidden while empty).

- Formats: PNG (transparent preferred), JPG, WEBP or SVG
- Recommended: at least 400 px wide, logo trimmed close to its edges
- File name = logo's alt text:  `tata-motors.png` → "Tata Motors"
- To control order, prefix numbers:  `01-tata-motors.png`, `02-...`
- 6+ logos scroll as a moving strip; 10+ logos use two rows

Only add logos of genuine clients, with their permission.
